A fast, secure, and user-friendly URL shortener built with modern web technologies. This application transforms long, cumbersome links into clean, shareable URLs, and instantly generates downloadable QR codes for seamless mobile access.

---

## ✨ Key Features

* **⚡ Lightning Fast Shortening**: Instantly convert long URLs into compact, manageable links.
* **📱 Integrated QR Codes**: Automatically generates a scannable QR code for every shortened URL, perfect for print or digital sharing.
* **🔒 Secure & Scalable Backend**: Powered by **Supabase** (PostgreSQL) for real-time, secure database operations.
* **🎨 Modern UI/UX**: Clean, responsive, and intuitive user interface built with React components.
* **📋 One-Click Copy**: Frictionless user experience with a "copy to clipboard" feature for new links.
